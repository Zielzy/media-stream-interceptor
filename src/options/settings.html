Webhook Auto-Forwarding

Automatically forward captured video streams and HTTP headers to a local or remote server.

When enabled, any new stream sniffed in the browser is sent via HTTP POST to the target URL below.
Enter any local or remote HTTP endpoint that accepts JSON POST requests.

Sniffer Filters

Tune which network media patterns are recorded.

When active, individual chunks (like .ts fragments) are hidden so only master playlists (.m3u8) and direct files are captured.
Limits memory consumption by pruning oldest streams when cap is reached.
